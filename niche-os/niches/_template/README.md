# Template ngách mới

Copy thư mục này thành `niches/<tên-ngách>/` rồi tạo 3 file:

1. `competitors.md` — chạy playbook 01. Bảng tầng A (Kênh · ID · Format · Hit tiêu biểu · Công thức), tầng B, tầng C, rồi "Kết luận ngách" (3–6 gạch đầu dòng).
2. `content-pool.md` — chạy playbook 02. Bảng "Khung title → biến số trống" + bảng ý tưởng đã chấm điểm /15.
3. `own-channels.md` — chạy playbook 03. Mỗi kênh: số liệu, chẩn đoán theo cây, quyết định đề xuất, nhật ký thí nghiệm.

Rồi append số liệu đối thủ vào `data/competitor-snapshots.csv`.

Danh sách kênh đầu vào: dán link/handle vào đây trước khi quét.
